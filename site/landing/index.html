How it works

Three steps, and the first one only once

There is no installer, no package and no daemon. The program is a single file.

1

Download

Get the one file, ngtop, for Linux x86_64. About @SIZE@.

2

Make it executable

Once only: chmod +x ngtop. That is the whole setup.

3

Run it

Type ./ngtop. The first frame appears in about 25 ms.

Features

Everything your machine is doing

Five sections, one keystroke apart: Overview, GPU, Processes, Network & Disks, Services.

Overview

Braille CPU graph and every core, memory, swap and zram, GPU, mirrored network graph, disks and a process list with GPU% and VRAM.

GPU

AMD (amdgpu) and Intel (i915, xe): per-process use and VRAM, engines, clocks, temperatures, fan, power, PCIe. Never wakes a sleeping discrete GPU.

Processes

A tree with folding, and details: threads, open files, sockets, environment, limits, cgroup. Signals and nice, always with confirmation.

Network & Disks

Interfaces, connections with the process that owns them, disk IOPS, latency, queue and temperature. A hung NFS mount never freezes the screen.

Services

systemd units: start, stop, restart, enable with confirmation (polkit asks the password), the journal of each unit, boot time and the slowest units.

Safe signals

Signals go through pidfd, so one can never reach a recycled PID. The subtree of PID 1 is protected.

Fits over SSH

The compact layout switches on by itself below 100×30 and fits an 80×24 terminal.

Keyboard and mouse

htop-style F-keys and full mouse support. Truecolor, 256 or 16 colours chosen automatically. °C or °F.

Light on the machine

Measured on an Intel N100: about 1 % CPU at the default 1 s refresh and about 5.6 MB of RAM.
